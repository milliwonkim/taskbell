TaskBell 개인정보 처리방침

최종 업데이트: 2026년 5월 29일

1. 수집하는 정보

TaskBell은 별도의 회원가입을 제공하지 않으며, 개발자가 직접 사용자의 이름, 이메일, 전화번호, 위치 정보 또는 광고 식별자를 수집하지 않습니다.

2. 사용자가 앱에 입력하는 데이터

사용자가 생성한 할 일, 알림, 메모, 반복 일정 등의 데이터는 앱 기능 제공을 위해 기기 내부에 저장될 수 있습니다. 사용자가 iCloud 동기화를 사용하는 경우 해당 데이터는 사용자의 iCloud 계정을 통해 Apple의 iCloud 서비스에 저장 및 동기화될 수 있습니다.

3. 알림

TaskBell은 사용자가 설정한 할 일과 일정 알림을 제공하기 위해 iOS 알림 기능을 사용합니다. 알림 권한은 사용자가 기기 설정에서 언제든지 변경할 수 있습니다.

4. 제3자 제공 및 추적

TaskBell은 사용자의 데이터를 광고, 추적 또는 판매 목적으로 제3자에게 제공하지 않습니다. 앱은 사용자를 추적하기 위한 광고 식별자나 제3자 추적 도구를 사용하지 않습니다.

5. 데이터 삭제

사용자는 앱에서 생성한 데이터를 직접 삭제할 수 있습니다. iCloud 동기화를 사용하는 경우 iCloud에 저장된 데이터는 Apple ID 및 iCloud 설정의 영향을 받을 수 있습니다.
